# 공부메이트

> 계획부터 복습까지, 매일 공부를 함께 챙겨 주는 스터디 플래너

UI/UX 프로그래밍 수업에서 한 학기 동안 발전시킬 서비스 소개 페이지입니다.

- 배포 주소: https://gomeasy95.github.io/ux-programming-01/

## 주차별 작업

- 1주차: 첫 웹페이지 만들기, GitHub Pages 배포
- 2주차: HTML로 서비스 소개 페이지의 구조 만들기 (CSS 적용 전)
- 3주차: 외부 CSS 파일을 연결해 서비스 소개 페이지 꾸미기

## 2주차 페이지 구조

```
body
├── header : h1(서비스 이름) · p(한 줄 소개) · nav(페이지 내부 이동 4개)
├── main
│   ├── section#about     : 서비스 소개 · 이미지
│   ├── section#features  : 주요 기능 3개 (ul)
│   ├── section#steps     : 이용 방법 3단계 (ol)
│   └── section#subscribe : 이메일 입력 + 시작 버튼 (form)
└── footer
```

## 구현하면서 바꾼 구조와 그 이유

- 처음 계획: 소개 → 기능 → 이용 방법 → 시작하기
- 1주차 자기소개 페이지를 서비스 소개 페이지로 바꾸고, 1주차 `<h1>`·`<p>`는 서비스 이름과 한 줄 소개로 고쳐 `<header>` 안으로 옮겼습니다.
- 주요 기능은 순서를 바꿔도 뜻이 같아 `<ul>`, 이용 방법은 순서대로 따라야 해서 `<ol>`을 썼습니다.
- 1주차에 넣었던 CSS는 이번 주가 HTML 구조에 집중하는 단계라 빼고, 다음 주에 다시 적용합니다.

## 3주차 CSS 적용

2주차에 만든 HTML 구조는 그대로 두고, 외부 스타일시트 한 개만 연결해서 꾸몄습니다.

```
index.html  ──(link)──  assets/css/style.css
```

```html
<link rel="stylesheet" href="./assets/css/style.css">
```

### 사용한 CSS 속성과 그 이유

| 속성 | 어디에 썼나 | 왜 썼나 |
| --- | --- | --- |
| `font-size` | h1 40px · h2 26px · h3 19px · 본문 16px | 글자 크기를 단계로 나눠 제목과 본문이 바로 구분되게 |
| `color` | 제목은 진한 파랑, 본문은 회색 계열 | 같은 상자 안에서도 제목이 먼저 읽히도록 |
| `background-color` | 페이지 연회색 · 영역 흰색 · 머리말 파랑 · 신청 영역 연파랑 | 배경색이 바뀌는 지점이 곧 영역이 바뀌는 지점 |
| `margin` / `padding` | 영역 사이 28px, 영역 안쪽 28px | 여백으로 정보 덩어리를 떼어 놓기 |
| `border` | 영역 왼쪽 굵은 선, 제목 아래 밑줄, 기능 카드 위쪽 선 | 선으로 영역의 시작과 제목의 끝을 표시 |
| `border-radius` | 상자·버튼 모서리 | 딱딱하지 않고 카드처럼 보이게 |

### 영역을 구분한 방법

- **머리말**: 대표 색(파랑) 배경 + 흰 글자로 맨 위를 확실히 분리하고, 메뉴는 흰 테두리를 둘러 버튼처럼 보이게 했습니다.
- **본문 영역**: `section` 네 개를 모두 흰 상자로 만들고 왼쪽에 굵은 파란 선을 넣어, 스크롤할 때 영역이 바뀌는 게 보이도록 했습니다.
- **주요 기능**: `ul`의 점 표시를 없애고 `grid`로 카드 3개를 나란히 놓았습니다. 화면이 좁아지면 자동으로 한 줄씩 내려옵니다.
- **이용 방법**: `ol`의 숫자만 대표 색으로 바꿔 순서가 있는 목록이라는 점을 강조했습니다.
- **무료로 시작하기**: 마지막 영역만 배경색을 연파랑으로 바꿔서, 실제로 눌러야 하는 곳이 눈에 띄게 했습니다.

### 그 밖에

- 색은 `:root`에 이름표(변수)로 모아 두고 가져다 썼습니다. 나중에 색을 바꿀 때 한 곳만 고치면 됩니다.
- `@media (max-width: 600px)`로 휴대폰 화면에서는 글자 크기와 여백을 줄였습니다.
- HTML은 `<link>` 한 줄만 추가했고 구조는 2주차 그대로입니다.
